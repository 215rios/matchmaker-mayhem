# Matchmaker Mayhem

## Description
Matchmaker Mayhem is a browser-based wedding matchmaking game built with HTML, CSS, and vanilla JavaScript. Players customize Person 1, choose their desired partner traits, filter a list of predefined characters for Person 2, and reveal a compatibility score with a playful wedding outcome.

## Features
- Character customization for Person 1
- Trait and partner preference selection
- Role-based partner filtering
- Compatibility score calculation from traits, preferences, and style match
- Wedding outcome result with a short narrative

## How to Run
1. Open the project folder.
2. Double-click `index.html`, or right-click it and open it in any modern web browser.
3. Fill out Person 1's role, style, traits, and desired partner traits.
4. Choose Person 2's role and select a partner.
5. Click `Matchmake` to see the result.

## Requirements
- A modern web browser
- No installation, dependencies, or server setup required

## File Structure
- `index.html` - Main page structure and app layout
- `styles.css` - Visual styling and responsive layout
- `script.js` - Matchmaking logic, filtering, and result rendering
- `README.md` - Project overview and run instructions
